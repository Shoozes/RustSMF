# Archived Research Notes

Move reviewed notes here only when keeping the raw source context has clear future value.

Keep an archived note when it:
- explains a rejected or superseded design decision that may be tempting to repeat
- preserves source names, dates, versions, links, or manual evidence needed for later audits
- documents an external blocker that cannot be represented fully in current state or TODOs
- supports a pitfall-ledger entry without duplicating the whole entry

Delete or leave out a reviewed note when its useful content has already been moved into `docs/dev/APP_STATE.md`, `docs/dev/TODO.md`, `docs/dev/PITFALL_LEDGER.md`, tests, or `summary_bank.json`, and the raw note adds no durable evidence.

Archived notes should keep their review-status block and a one-line reason for retention.
